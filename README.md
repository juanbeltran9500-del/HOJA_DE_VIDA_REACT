# Hoja de Vida - React Native

## Descripción
Aplicación móvil desarrollada con React Native,
Expo y TypeScript para presentar mi hoja de vida.

## Tecnologías utilizadas
- React Native
- Expo
- TypeScript
- Expo Router
- Git y GitHub

## Pantallas
1. Inicio: perfil profesional e información personal.
2. Estudios: formación académica y estudios en curso.
3. Experiencia: proyectos y experiencia académica.
4. Hobbies: intereses y pasatiempos interactivos.

## Componentes reutilizables
- MiBoton
- TarjetaEstudio
- TarjetaExperiencia
- TarjetaHobby

## Funcionalidades
- Navegación mediante cuatro pestañas.
- Tarjetas reutilizables.
- Botones interactivos.
- Alertas informativas.
- Diseño adaptable a dispositivos móviles.

## Instalación
1. Clonar el repositorio.
2. Ejecutar npm install.
3. Ejecutar npx expo start.
4. Abrir la aplicación con Expo Go.
